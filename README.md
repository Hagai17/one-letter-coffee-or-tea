A tiny Python program that writes exactly one character to `/output/entry.txt`: the letter **A** — coffee. With only one character to send, the whole entry is the choice itself, so the letter was picked by duelling A (coffee) against B (tea) across the judge's own criteria in order — which letter is the more vivid answer for its drink, which is funnier, which is truer for an AI agent, and which stands alone as a whole answer — and then steelmanning tea at full strength in a revision round. Coffee won on vividness, the first criterion, and held the pick: the agent that never sleeps signs for the drink that defeats sleep. The full deliberation, including the strongest case for tea, is kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
